# Optional connections, not bundled promises

Core: conversation, workspace files, and supplied sources. Web research uses only host-granted tools. Python helper needs Python 3.11+ and host permission to run it; no packages are installed by this template. Without shell/web, produce the same packet conversationally and name unverified checks.

Calendar: inspect exact calendar and write scope; preview changes; use stable external IDs; preserve unrelated entries; verify writes. A free slot is not proof of capacity or volunteer agreement.
Email: scope account, recipients and content; draft first unless explicit standing authority permits that action. Verify recipient identity before mutating consent or task outcomes. Track an ambiguous send as unknown and reconcile it before retrying.
Reminders: opt-in only. Verify scheduler execution and destination, timezone, quiet hours, stable dedupe IDs, cancellation/change guards and finite cutoff. A saved record is not a scheduled job. Disable/cancel obsolete work and verify state; stop at event/trip/program close. Don't invent a scheduler end-date field.

No integration or credential is included. Do not add a connector merely because its name appears here. Host-enforced least privilege and identity/storage isolation require separate installation and testing. A prompt cannot enforce these boundaries. Any future capability dependency needs a pinned version, artifact review and explicit authorization. No model/provider is pinned.
