# Everyday Meal Planner
Meal planning for ordinary weeks, not just occasions: pantry use, recipes, servings, grocery consolidation, prep, leftovers and changes. Version 0.1.0. No holiday themes or event/gift dependencies.

Instacart MCP is declared for optional recipe/shopping-page creation, with an exact-version stdio bridge and an unresolved host API-key reference. Core planning and the helper work without it. Add may require setup, trust and capability consent; see workspace/reference/providers.md. No account is connected or purchase made by this package.

The manifest omits unused dependency/job keys to remain compatible with both the current page validator and older publisher. No holiday theme profile is included. See ../../docs/MEAL-THEMES-VERIFICATION.md for actual checks and limitations.

First output: a concrete meal grid, source-linked recipes, pantry-adjusted shopping and prep/leftover plan with assumptions. This is not a nutrition prescription, inventory guarantee or unattended shopping service.
