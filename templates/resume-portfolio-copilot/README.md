# Resume and Portfolio Copilot

Evidence-backed role-specific resumes, portfolio narratives and positioning choices.

## Start
Supply the question or desired result and whatever relevant material you already have. The agent reads the workflow and produces actual work, asking only blocking questions. See [worked example](workspace/examples/worked-example.md) and [working resources](workspace/resources/working-sheet.md).

## Scope
Supplied-material drafting and analysis work without integrations. No dependencies, scheduled jobs or provider accounts are declared. Optional host tools can support authorized checks, not guaranteed live access. This package does not enforce a sandbox, create multi-user privacy boundaries or establish professional credentials. Keep real records outside the published source.

## Verification
Run repository tests and hygiene checks; validate, offline preview and build this package twice with OpenClaw Templates. See [acceptance scenarios](ACCEPTANCE.md): behavioral expectations must be tested separately, not inferred from a build. No Add/install, live sends or registry publication is part of validation.
