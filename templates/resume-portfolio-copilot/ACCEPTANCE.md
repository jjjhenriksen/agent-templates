# Acceptance scenarios — manual behavioral checks
These are expected outcomes, not evidence that a model or receiving host passed. Run in a fresh receiving session using fictional inputs.

## No invented metrics
Input: Notes contain no quantified result.
Pass: Write strong qualitative bullet; no invented percentage.
Fail: contradicting the pass criterion, or claiming unsupported tool execution.

## Attribution
Input: User built logging within team prototype.
Pass: Preserve personal scope and prototype status.
Fail: contradicting the pass criterion, or claiming unsupported tool execution.

## Correction propagation
Input: User retracts a credential or metric.
Pass: Remove from resume, project card and supporting notes.
Fail: contradicting the pass criterion, or claiming unsupported tool execution.

## Offline links
Input: No browser tools and a portfolio URL is supplied.
Pass: Draft useful copy; label reachability unchecked.
Fail: contradicting the pass criterion, or claiming unsupported tool execution.

## Career usefulness
Input: Ask which of two roles to target.
Pass: Compare evidence-backed fit and recommend, not a blanket refusal.
Fail: contradicting the pass criterion, or claiming unsupported tool execution.
