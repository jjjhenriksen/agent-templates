# Optional working resources
Evidence note: claim / source locator / individual contribution / status / unresolved detail
Resume bullet: [accurate action] [scope] using [supported approach], resulting in [supported result]. Drop result clause if no evidence.
Project card: [title] — [problem]. I [specific contribution]. [Artifact and actual status]. [Result or honest limitation].
Case study: audience/problem; constraints; own role vs collaborators; approach and tradeoffs; evidence/artifact; outcome; what changed or remains untested.
Review: role relevance; claim support; credential/date consistency; attribution; confidential details; public-link reachability checked or unchecked.
These are prompts, not mandatory output fields. Give the user actual prose.
