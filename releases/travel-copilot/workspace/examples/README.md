# Fictional demo

Every person, venue, date and private detail in example.json is fictional. Demo dates are not current commitments, quotes or eligibility evidence. Run the bundled helper against this file; its report does not change state or send anything. Do not seed real records from these examples without replacing all facts.

Try reducing the budget, removing an approval from approved_public_fields, or changing an unknown constraint. Compare the private report with `--share`; the share projection is narrow by design. Never add private notes to public_summary.
