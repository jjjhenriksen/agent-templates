# Architecture

Each templates/<slug>/ directory is a standalone OpenClaw package. package.json points at CLAW.md. Its YAML manifest explicitly maps every workspace asset; the body becomes managed SOUL.md. Root BOOTSTRAP.md is the separate one-time intake. AGENTS.md defines authority, record maintenance and evidence discipline. No competing SOUL mapping, package lifecycle scripts, extensions, MCP servers, jobs, credentials or model pin.

The agent supplies conversation, synthesis and source interpretation using host-granted tools. The optional standard-library Python helper reads one private JSON record and prints a report; it does not persist state, call the network or authenticate facts. It is executable content to inspect, not a guaranteed host permission. If Python or shell is absent, the agent still works from supplied text with explicitly unverified calculations.

Celebrations: decimal forecast + task dependency checks. Travel: explicit party-total math + unresolved hard constraints. Good Company: greedy candidate screening with opt-in, declared roles/skills, windows, workload and proposed overlap avoidance. It is not globally optimal scheduling or qualification verification.

Public exports are an allowlisted projection with explicit field approvals. This prevents exporting arbitrary structured private fields, not secrets placed inside an approved string. Human/agent semantic review and genuine access controls remain essential. Single trusted organizer is the supported audience.

Good Company operational upgrade: wrap the original engine with narrow, authenticated tools (plugin or pinned MCP), real persistent state, provider scopes, recipient identity and transactional reconciliation. Separately test revocation, concurrent claims, ambiguous outcomes, message budgets and scheduler execution. Do not install that engine as an incidental template side effect.
